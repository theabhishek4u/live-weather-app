# 🌦️ Live Weather App

A sleek and simple web application to check real-time weather updates for any city using OpenWeatherMap API.

[Click here to view the live app](https://your-live-site-link.com)

## 🛠️ Features

- 🌍 Get current weather by city name
- 🌡️ Temperature, humidity, wind speed, weather description
- 🎨 Clean and responsive UI
- 🌙 Dark/light mode support (optional)
- 📍 Geolocation support (optional)

## 🚀 Technologies Used

- HTML5
- CSS3 (or TailwindCSS / Bootstrap)
- JavaScript (Vanilla / React / Vue)
- [OpenWeatherMap API](https://openweathermap.org/api)
